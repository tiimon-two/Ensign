Тестовое задание компании Энсайн. Задача - сверстать десктопную версию главной страницы с помощью AI инструментов. 
Код вёрстки и стилей изначально генерировался с помощью плагина Figma Anima, позже проверялся и дополнялся с помощью DeepSeek.
В конце вносились ручные правки.
Для работы слайдеров использовался slick slider, для select - select 2 jquery.
Стили писались с использованием SCSS.
Запуск проекта: npm run dev
